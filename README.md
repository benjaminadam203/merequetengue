# Senhas Pokémon

Projeto simples de página web para gerar uma senha codificada com temática de Pokémon.

## O que ele faz

- recebe uma senha digitada pelo usuário
- transforma cada caractere em um Pokémon da lista
- exibe a sequência em cards visuais com imagens oficiais
- mostra a senha codificada em formato numérico

## Estrutura

- `index.html` — página principal
- `style.css` — visual do projeto
- `senhas.svg` — imagem/logo da aplicação
- `README.md` — documentação

## Como usar

1. abra o arquivo `index.html` em um navegador
2. digite sua senha
3. clique em `Codificar`
4. veja a sequência Pokémon gerada

## Observação

Este projeto é apenas educativo e visual. Ele não substitui um sistema real de segurança para senhas.
